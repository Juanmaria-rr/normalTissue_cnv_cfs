Breakend: boundary between two segments (≥ 1 Mb) of different copy-number state in one cell; interval = one bin each side.

Main definition E2–E4: flank ratio > 1.3 or < 0.7, the paper’s threshold.

Event: breakends of one donor, same chromosome, direction and type within 2 Mb, collapsed; a clone counts once.

Interstitial: the interval does not touch a pericentromeric block ± 1 Mb.

Bins of 200 kb, 500 kb and 1 Mb run in parallel; 500 kb shown. Source: funnel_cells.tsv, events_500kb.tsv
