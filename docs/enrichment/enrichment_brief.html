1 · Question and data

Do interstitial copy-number breakends of normal breast epithelial cells (Lin et al. 2024, PRJNA1003661) overlap common fragile sites (CFS) more often than expected under a null that keeps chromosome and replication timing? Three tests answer it with different units and nulls; all are exploratory (no primary hypothesis was declared before the pilot).

Cells

Main set: 2,052 / 5,032 / 6,297 cells at 200 kb / 500 kb / 1 Mb, of 9,181 imaging-selected cells. Cuts: ≥ 15 reads per usable bin per copy (diploid), noise_excess ≤ 1.5, rt_rho ≤ 0.10 (S phase).

Breakend

Boundary between two segments (≥ 1 Mb of usable bins) of different state in one cell; interval [lo, hi] = one bin on each side. Main definition E2–E4: flank ratio > 1.3 or < 0.7 (the paper's threshold).

Event

Breakends of one donor with the same chromosome, direction and type within 2 Mb, collapsed into one: a clone counts once. Interstitial = interval does not touch a pericentromeric block ± 1 Mb.

Events tested

Interstitial E2–E4 losses / gains: 200 kb 71 / 232 · 500 kb 93 / 186 · 1 Mb 86 / 72.

Site sets. Eight published CFS catalogues, derived sets and two gene-size controls; see section 2.

Multiple testing. Benjamini–Hochberg over all 198 main-stratum rows of the CFS sets (sets × bins × directions; controls excluded): q global on the exact p, q perm. global on the permutation p. A q computed within one set only (q family) is in the full tables but does not control the error across sets.

2 · Site sets (CFS catalogues)

Names. Each set is written <catalogue>:<cell type>: the catalogue is the source study (first author and year) and the cell type the line in which the sites were measured; :all is the union of all the catalogue's cell types (for example macheret2020:all = MiDAS domains of HS68, HeLa and U2OS; letallec2013:MCF10A = sites mapped by FISH in MCF10A breast epithelial cells). Gene controls have no cell type.

Three kinds. Measured catalogues each capture one facet of fragility in specific cell types (MiDAS = DNA synthesis in mitosis after mild aphidicolin; replication delay; FISH or cytogenetic breaks; CNV or cancer-SV hotspots). Derived sets combine them (consensus) or predict fragility in breast epithelium (breast_predicted). Controls are genes > 300 kb and > 1 Mb: most CFS lie in very large genes, so an enrichment at CFS should be read against an enrichment at large genes as such. All coordinates are hg19 (hg38 sources lifted with the UCSC chain).

3 · Test A: events re-placed on the genome

  • Unit: one event. Observed O: events whose [lo, hi] overlaps the set.
  • Null: each event is moved, with its width, to every usable-bin start of its own chromosome where the placement has the event's replication-timing quintile and does not touch a pericentromere; pi = fraction of those placements that overlap the set (exact). E = Σ pi; fold = O / E.
  • p perm. (reference): the set is shuffled 5,000 times (each site to a random usable bin of the same chromosome and RT quintile) and the fold recomputed; it keeps the clustering of events and sites. The exact Poisson-binomial p assumes independent events and is smaller.

4 · Test B: regression on 1 Mb windows

  • Unit: donor × usable 1 Mb window outside pericentromeres. Each event is assigned to the window it overlaps most (events overlapping no eligible window are excluded and counted).
  • Model: Poisson (negative binomial if over-dispersed): events ~ overlaps set (yes/no) + RT + GC + mappability + chromosome + donor, offset log(usable fraction). IRR = event rate in windows of the set relative to the rest.
  • Standard error = the larger of the model-based and the chromosome-clustered one. Rows with no event in set windows have no estimate (separation).
  • Also fitted: crude (set + donor) and adjusted + fraction of the window in genes > 300 kb. Large genes are probably part of the fragility mechanism, so that model is conservative.

5 · Test C: every cell's breakend, per donor

  • Unit: one breakend of one cell, not collapsed: a clone weighs as many times as it has cells. o and pi as in test A.
  • Per donor and pooled: O/E with a 95% CI from resampling cells (2,000 times; one-sided upper bound 3.0 / E when O = 0). Heterogeneity between donors: X² on donors with E ≥ 1.
  • It asks whether the excess is shared by donors and how clonal expansion changes it; it mixes break rate with clonal expansion.

7 · What limits these results

  • Five donors and few events: the strongest row rests on 10 events; per-donor expectations are below 1–2.
  • No pre-declared primary test: the strongest row was picked from 198 tests; only the global q values account for that.
  • Events cluster (clones, recurrent regions, donor-specific losses): the permutation p is larger than the exact p.
  • Resolution: breakend intervals (≥ 2 bins) are about as wide as the sites; the bins are not independent replications (different cells and widths), hence the cells500 and refined variants.
  • Catalogues and replication timing come from other cell types (tumour lines, lymphocytes, fibroblasts).
  • Scale-up to 49 donors (expected events × 9.05): macheret2020:HS68 at 500 kb loss: smallest fold detectable with 80% power at a global α ≈ 2.11; consensusA:core at 500 kb loss: smallest fold detectable with 80% power at a global α ≈ 1.46; macheret2020:all at 500 kb loss: smallest fold detectable with 80% power at a global α ≈ 1.33 (full document, section 10).
