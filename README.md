# CNV_cfs — copy-number breakends vs common fragile sites in normal breast scDNA-seq

> **Public snapshot.** This repository is a periodic copy of a private working repository, published to show the analysis. Infrastructure identifiers are replaced by placeholders (e.g. `<AWS_ACCOUNT_ID>`, `<PROJECT_BUCKET>`), and internal material (AWS cost reports, the group's curation app) is not included. Analysis outputs (`results/`) are not versioned.

Per-cell copy-number (CN) profiling of the normal-breast single-cell DNA-seq dataset
**PRJNA1003661** (Lin et al., *Nature* 636:663, 2024), and a test of whether CN breakends
fall in common fragile sites (CFS) more often than expected. Genome build: **hg19**.

Full methodology, decisions and results are in the documents (see [Documents](#documents));
this README only orients.

## Status (2026-11-05)

## Reproduce

```bash
git clone --recurse-submodules https://github.com/Juanmaria-rr/CNV_cfs.git

# metadata and pilot (supplementary PDF 41586_2024_8129_MOESM1_ESM.pdf in data/metadata/)
python3 scripts/00_metadata/build_cell_metadata.py --out-dir data/metadata
python3 scripts/00_metadata/parse_suppl_tables.py --pdf data/metadata/41586_2024_8129_MOESM1_ESM.pdf --out-dir data/metadata
Rscript scripts/00_metadata/count_usable_bins.R data/metadata/usable_bins.tsv
python3 scripts/00_metadata/select_pilot_cells.py --cells data/metadata/cells.tsv --donors P08 P07 P36 P20 P18 --out-dir data/pilot

# AWS: staging, images and workflows — see docs/AWS_RUNBOOK.md
bash containers/build_push.sh align && bash workflows/deploy_workflow.sh align

# CFS catalogues
python3 scripts/05_features/build_cfs_catalogs.py --raw data/features/cfs/raw --out data/features/cfs --letallec <mmc4.xlsx>
python3 scripts/05_features/build_gene_features.py --raw data/features/genes/raw --out data/features/genes
python3 scripts/05_features/build_breast_predicted_cfs.py ...   # see the script header
python3 scripts/05_features/build_cfs_consensus.py --cfs data/features/cfs/cfs_catalogs_hg19.tsv \
    --breast data/features/cfs/breast_predicted_cfs_hg19.tsv --out data/features/cfs

# enrichment analysis end to end (event tables, tests, master tables, figures, document)
bash scripts/06_enrichment/run_all.sh
```

Every script documents its inputs, outputs and method in its header.
Requirements: Python ≥ 3.10 with pandas, numpy, scipy, statsmodels, matplotlib, pyliftover,
xlrd, openpyxl, nbformat/nbconvert; R with QDNAseq; `curl`, `pdftotext`, Docker, AWS CLI.

## Known limitations

- Depth depends on the sequencing batch, so depth-based cell selection is partly batch selection.
- Replication timing and most CFS catalogues are not from breast epithelium.
- The pilot has 5 donors; event counts are small and results are exploratory.
- Breakends are inferred from CN changes only (no junctions, no balanced events).
